## Applied Machine Learning & Data Engineering
- [depression-severity-dbs](https://github.com/sophiapouya/depression-severity-dbs/tree/dbs-paper): End-to-end ML pipeline predicting clinical depression severity from intracranial neural signals. Applied PCA and regularized regression (Ridge, Lasso) to 300+ features per session across 7 patients, achieving statistically significant decoding in 83% of the cohort.
- [ieeg-analysis](https://github.com/sophiapouya/ieeg-analysis): Python pipeline for processing intracranial EEG data from 15+ epilepsy patients, including bandpass/notch filtering, Hilbert-based spectral decomposition, and log-transformed power feature extraction.
- [electrode-localization](https://github.com/sophiapouya/electrode-localization): Automated pipeline using FreeSurfer and ANTs to register CT/MRI data and map intracranial electrode coordinates to MNI space and anatomical regions.

## Clinical Research & Experiment Design
- [single-neuron-analysis](https://github.com/sophiapouya/single-neuron-analysis): Analysis of single neuron recordings during a Stroop task across amygdala, hippocampus, pre-SMA, and prefrontal cortex, including PSTHs and permutation-based cluster testing.
- [conflict-monitoring-action-inhibition-experiment](https://github.com/sophiapouya/conflict-monitoring-action-inhibition-task): PsychoPy-based behavioral task built in Python/Linux to study action inhibition and conflict monitoring, with real-time stimulus control and behavioral logging.
